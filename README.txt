ربات انتشار خودکار «گره درخت دل»

تنظیم پیش‌فرض:
- ۹:۰۰ صبح
- ۱۸:۰۰ عصر
- ۲۳:۰۰ شب
- منطقه زمانی: ایران
- ۳۰ پست به‌ترتیب و سپس تکرار از ابتدا

راه‌اندازی:
1) فایل .env.example را به .env تغییر نام بده.
2) توکن جدید BotFather را فقط داخل .env وارد کن.
3) نصب:
   pip install -r requirements.txt
4) اجرا:
   python main.py

برای روشن ماندن دائمی، پروژه باید روی یک کامپیوتر همیشه روشن یا سرویس میزبانی اجرا شود.
